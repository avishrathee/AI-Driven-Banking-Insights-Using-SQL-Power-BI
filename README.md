# AI-Driven-Banking-Insights-Using-SQL-Power-BI

First, I used Perplexity AI to generate a synthetic banking dataset containing around 10,000 transaction records. I intentionally included some data-quality issues,
such as missing values, duplicate records, inconsistent date formats, and unusual transaction amounts.
Next, I created three tables in SQL Server: Customers, Accounts, and Transactions. I used LEFT JOINs to combine these tables into a single dataset for analysis.
After that, I performed data cleaning and transformation using Power Query Editor.
Finally, I developed a two-page interactive Power BI dashboard with 6 KPIs, supported by charts and visualizations to present financial and operational insight
